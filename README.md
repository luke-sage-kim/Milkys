## 📁 프로젝트 소개


  
> 이 프로젝트는 밴드원들의 합주곡 선정 녹음버전관리 합주스케줄등을 관리 등 전반적인 밴드 활동을 보조해주는 사이트입니다.

---

## 🛠 사용 기술 스택

| 분류           | 기술                                       |
|----------------|--------------------------------------------|
| 언어           | Java, JavaScript                           |
| 프론트엔드     | React, HTML, CSS, Tailwind CSS             |
| 백엔드         | Spring Boot, JPA                           |
| 데이터베이스   | MySQL (AWS RDS)                            |
| 배포 / 인프라  | AWS EC2, S3, CloudFront, Nginx             |

## 🚀 설치 및 실행 방법

```bash
# 1. 레포지토리 클론
git clone https://github.com/your-id/project-name.git

# 2. 백엔드 실행
cd backend
./gradlew bootRun

# 3. 프론트엔드 실행
cd frontend
npm install
npm start
